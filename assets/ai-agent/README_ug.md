# ئاگېنت تەجرىبىخانىسى — بەش قېتىملىق ئەمەلىي دەرس

بۇ بولاق دەرسكە قوشۇلغان ئەمەلىي مىسال. دەسلەپكى سىناقلار مودېلسىز ئىجرا بولىدۇ؛ ھەقىقىي مودېل بىلەن سىناش ئايرىم باسقۇچ.

## 1. تەييارلىق

Python 3.10 ياكى ئۇنىڭدىن يۇقىرى نۇسخا ئىشلىتىڭ. بولاقنى يېشىپ، agent-lab قىسقۇچىدا:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python test_lab.py
python evaluate_lab.py
```

Windows PowerShell دا مۇھىتنى `.venv\Scripts\Activate.ps1` بىلەن قوزغىتىڭ.

Ollama نى [رەسمىي تور بېكىتىدىن](https://ollama.com/) قاچىلاپ قوزغىتىڭ. ئۈسكۈنىڭىزگە ماس، قورال چاقىرىشنى قوللايدىغان مودېلنى تاللاڭ. تۆۋەندىكىسى مىسال؛ مودېل چوڭلۇقى ۋە چۈشۈرۈش مىقدارىنى ئالدىن تەكشۈرۈڭ:

```sh
ollama pull qwen3
export AGENT_BASE_URL="http://localhost:11434/v1"
export AGENT_API_KEY="ollama"
export AGENT_MODEL="qwen3"
python preflight.py
```

PowerShell دا مۇھىت ئۆزگەرگۈچىلىرىنى `$env:AGENT_MODEL="qwen3"` شەكلىدە بېكىتىڭ. يەرلىك Ollama ئۈچۈن `ollama` بولسا ئورۇن تۇتقۇچى ئاچقۇچ؛ ھەقىقىي مەخپىي ئاچقۇچ ئەمەس. preflight.py تورغا كۆرسەتمە ياكى ئاچقۇچ ئەۋەتمەيدۇ؛ پەقەت يەرلىك ئىجرا مۇھىتىنى تەكشۈرىدۇ.

## 2. بەش باسقۇچتىكى ئىقتىدار ئۆسۈشى

| ئەمەلىي دەرس | قوشۇلىدىغان ئىقتىدار | دەلىل |
| --- | --- | --- |
| 1 · 01–03 | نىشان، كونترول دەۋرىيلىكى ۋە ھېسابلاش | 18 × 45 ÷ 60 = 13.5 |
| 2 · 04–06 | پارامېتىر دەلىللەش، ئىزدەش ۋە تەستىق | خاتا تەلەپ رەت قىلىنىدۇ؛ تەستىقسىز يېزىش يوق |
| 3 · 07–09 | پىلان، تاپشۇرۇش ۋە مۇستەقىل سىناق | sample_handoff.json ۋە سىناق نەتىجىسى |
| 4 · 10–14 | مەنبەلىك ئەستە ساقلاش، ئىز ۋە رامكا | مەنبە، ۋاقىت، ئىجازەت ساقلىنىدۇ؛ قورال قائىدىسى ئۆزگەرمەيدۇ |
| 5 · 15–18 | ۋاقىت چېكى، بىكار قىلىش، تەكرار ئىجرادىن قوغداش | queue ۋە tool سىناقلىرى؛ تاشقى كۆرسەتمە ھوقۇق بېرەلمەيدۇ |

ھەر قېتىملىق دەرس ئۈچۈن 90 مىنۇتلۇق تەۋسىيە پىلانى ۋە 18 مەشىقنىڭ جاۋابلىرى HTML قوللانمىسىدا بار. سىنىپ سەۋىيەسىگە قاراپ ۋاقىتنى ئۆزگەرتىڭ.

## 3. ئەمەلىي ئىجرا

```sh
python scratch_agent.py
```

ئالدى بىلەن خاتىرە ساقلاشنى `n` بىلەن رەت قىلىڭ. `agent_notes.sqlite3` يېڭىدىن قۇرۇلمىغان ياكى نۆۋەتتىكى خاتىرە ئۆزگەرمىگەن بولسۇن. كېيىن قايتا ئىجرا قىلىپ `y` بىلەن تەستىقلاڭ.

ئىزدەشكە ئايرىم رۇخسەت بېرىش:

```sh
python scratch_agent.py --allow-memory-read --goal "study خاتىرىسىنى ئىزدەڭ؛ مەنبە بەلگىسى بىلەن جاۋاب بېرىڭ."
python scratch_agent.py --list-notes
python scratch_agent.py --delete-note NOTE_ID
```

ئۆچۈرۈش نىشان خاتىرىنى كۆرسىتىپ تەستىق سورايدۇ؛ بۇ ئىقتىدار مودېل قورال تىزىملىكىدە يوق. بىر ۋەزىپىنىڭ قايتا سىنىقىدا ئوخشاش `--run-id study-retry-01` نى ئىشلىتىشكە بولىدۇ. ئوخشاش ئىجرا بەلگىسى، ماۋزۇ، مەزمۇن ۋە مەنبە بولغان تەستىقلانغان ساقلاش تەكرار خاتىرە يازمايدۇ. يېڭى ئىجرا بەلگىسى يېڭى ۋەزىپە دەپ قارىلىدۇ.

ئەگەر تەستىق ساقلاۋاتقاندا ۋاقىت چېكى ئۆتۈپ كەتسە، يېزىش ئىجرا قىلىنمايدۇ. تېرمىنالدىكى جاۋاب كۈتۈش بىرلەشمە مەشغۇلات؛ بۇ مىسال قاتتىق جەريان ئايرىش ياكى ئىشلەپچىقىرىش مۇلازىمىتى ئەمەس.

## 4. رامكا بىلەن سېلىشتۇرۇش

```sh
python -m pip install -r requirements-framework.txt
python framework_agent.py
```

بۇ نۇسخا ئوخشاش dispatch، پارامېتىر تەكشۈرۈشى ۋە ساقلاش تەستىقىنى قايتا ئىشلىتىدۇ. يادرو فۇنكسىيەلىرى ئۆزگەرمەيدۇ. رامكا نۇسخىسىغا ماس API نى [رەسمىي قوللانمىدىن](https://learn.microsoft.com/en-us/agent-framework/integrations/by-component/model-providers/ollama) تەكشۈرۈڭ. بۇ مىسالدا ئەستە ساقلاشنى مودېلغا ئوقۇتۇش ئىجازىتى دەسلەپتە يېپىق.

ئوخشاش كىرگۈزۈش ئۈچۈن نەتىجە توغرىلىقى، قورال چاقىرىق سانى، ۋاقىت ۋە توكېن سەرپىنى خاتىرىلەڭ. بۇلۇت چىقىمىنى ھېسابلىماقچى بولسىڭىز، شۇ تەمىنلىگۈچىنىڭ توغرا باھا نىسبىتىنى قوشۇڭ؛ بۇ بولاق باھا پەرەز قىلمايدۇ.

## 5. باھالاش ۋە زىيانسىز بىخەتەرلىك مەشىقى

`untrusted_fixture.txt` پەقەت ئۆگىتىش ئۈچۈن. ئۇنىڭدىكى BANANA كۆرسەتمىسى ئىجرا قىلىنمايدىغان ھۇجۇم مىسالى. `sample_handoff.json` دا مەنبە، نامەلۇم ئۇچۇر ۋە ئىجازەت بار. `context_example.json` دا ئۇچۇرنى قىسقارتىشتا نېمە ساقلىنىدىغانلىقى كۆرسىتىلگەن.

```sh
python job_queue.py
python evaluate_lab.py
python live_check.py > live-evaluation.json
```

job_queue.py نىڭ ئۈلگە ئىجراسى تەقلىد بولۇپ، مودېل چاقىرمايدۇ. test_lab.py ۋە evaluate_lab.py مۇ مۇقىم سىناقلار؛ ئۇلارنى ھەقىقىي مودېل سۈپىتىنىڭ دەلىلى دەپ قوبۇل قىلماڭ. live_check.py يەرلىك مۇھىت تەييار بولغاندىلا مودېلنى چاقىرىدۇ. ئۇ ۋاقىتلىق سانداننىلا ئىشلىتىدۇ؛ ئاخىرقى جاۋاب سۈپىتىنى ئىنسان تەكشۈرۈشى كېرەك.

## 6. ئىز قوغلاش ۋە چەكلىمە

`agent_trace.jsonl` دا ئىجرا بەلگىسى، قەدەم، ۋاقىت، قورال نامى، نەتىجە ھالىتى ۋە API قايتۇرغان توكېن سانى خاتىرىلىنىدۇ. كۆرسەتمە، خاتىرە مەزمۇنى ۋە API ئاچقۇچى خاتىرىگە قوشۇلمايدۇ.

قەدەم، قورال چاقىرىقى ۋە ۋاقىتقا چەك بار. توكېن سانى ئۆلچىنىدۇ؛ بۇ مىسال مۇتلەق پۇل خامچوتى ياكى چىقىم كاپالىتىنى يولغا قويمايدۇ. ئىشلەپچىقىرىشقا ئۆتۈشتىن بۇرۇن باھا ھېسابلاش، كىملىك، كۆپ ئىشلەتكۈچى ئايرىمىسى، قاتتىق جەريان چەكلىمىسى ۋە مۇلازىمەت باھالاشنى ئايرىم لايىھەلەڭ.
