# ئۇيغۇرچە ئۆزئارا تەسىرلىك ئاگېنت دەرسلىكى

## ئېچىش

تۈرنىڭ ئاساسىي قىسقۇچىدىكى [AI_agent_lesson.html](../../AI_agent_lesson.html) ھۆججىتىنى توركۆرگۈچتە بىۋاسىتە ئېچىڭ. يەرلىك مۇلازىمېتىر، تور ئۇلىنىشى، Python، مودېل، API ئاچقۇچى ياكى سىرتقى مۇلازىمەت كېرەك ئەمەس. `css`، `js` ۋە `assets` قىسقۇچلىرىنىڭ نىسپىي ئورنىنى ساقلاڭ.

ئىلگىرى تەمىنلەنگەن «18.html» دىكى 18 دەرسنىڭ تەرتىپى ۋە ئاساسىي قارار قائىدىلىرى ساقلاپ قېلىندى. يېڭى ئۇچۇردىكى مەنبە ئورنىغا تولۇق تېكىست قوشۇلمىغاچقا، شۇ مەۋجۇت مەنبە ئىشلىتىلدى. يېڭى تەجرىبە ۋە سوئاللار «مەشىق مىسالى» دەپ بەلگىلەندى.

ئىلگىرىكى كۆرسىتىش نۇسخىسى [AI_agent_presentation.html](../../AI_agent_presentation.html) دا ساقلاپ قېلىندى؛ ئوقۇش ۋە تەجرىبە ئۈچۈن يېڭى `AI_agent_lesson.html` نى ئىشلىتىڭ.

## ئۆگىنىش يولى

1. باش بەتتىن دەرسنى باشلاڭ ياكى تىزىملىكتىن دەرس تاللاڭ.
2. نىشان، ئاددىي چۈشەندۈرۈش ۋە قارار قائىدىسىنى ئوقۇڭ.
3. «مەشىق مىسالى» دا كىرگۈزۈلمىنى ئۆزگەرتىپ، كۆرۈنۈش، نەتىجە ۋە سەۋەبىنى سېلىشتۇرۇڭ.
4. تەكشۈرۈش سوئالىغا جاۋاب بېرىڭ؛ «توغرا» ياكى «خاتا» ئىنكاسى بىلەن سەۋەبىنى ئوقۇڭ.
5. «دەرسنى تاماملاش» نى بېسىڭ. ئاخىرقى ئېچىلغان دەرس، تاماملانغان دەرسلەر، سوئال جاۋابى ۋە ھەرىكەت تەڭشىكى مۇشۇ توركۆرگۈچتە ساقلىنىدۇ.

«ھەرىكەتنى توختىتىش» تەگلىك ھەرىكىتى ۋە ئاپتوماتىك قەدەم كۆرسىتىشنى توختىتىدۇ. قولدا قەدەم ئالماشتۇرۇش ۋە بارلىق قارار مەشىقلىرى داۋاملىق ئىشلەيدۇ. ئۈسكۈنىنىڭ `prefers-reduced-motion` تەڭشىكىمۇ ھۆرمەت قىلىنىدۇ.

تېلېفوندا يۇقىرىدىكى تىزىملىك بەلگىسىنى ئېچىڭ. كۇنۇپكا تاختىسىدا `Tab`، `Shift+Tab`، `Enter` ۋە بوشلۇق كۇنۇپكىسىنى ئىشلىتىشكە بولىدۇ؛ `Escape` ئېچىلغان تىزىملىكنى تاقايدۇ.

## مەزمۇننى ئۆزگەرتىش ياكى يېڭى دەرس قوشۇش

بىردىنبىر مەزمۇن مەنبەسى: [assets/ai-agent/lessons.json](../../assets/ai-agent/lessons.json).

ھەر بىر خاتىرىدە دەرس تېكىستى، ئۆگىنىش نىشانى، `theme`، `demo` ۋە `quiz` بىر يەردە تۇرىدۇ. ھازىرقى خاتىرىنى كۆچۈرۈپ، يېڭى تەكرارلانمىغان `id` بىلەن تىزىملىكنىڭ ئاخىرىغا قوشۇشقا بولىدۇ. ئاندىن تۈرنىڭ ئاساسىي قىسقۇچىدا:

```sh
python3 scripts/build-ai-agent-lesson.py
```

بۇ بۇيرۇق مەزمۇننى HTML نىڭ ئىچىگە قىستۇرىدۇ. بەت JSON نى `fetch` بىلەن ئوقۇمايدۇ؛ شۇڭا `file://` ئارقىلىق ئېچىلغاندىمۇ ئىشلىيدۇ. ھاسىل قىلىنغان HTML نى قولدا تەھرىرلەشنىڭ ئورنىغا JSON ۋە مۇناسىۋەتلىك CSS/JavaScript نى تەھرىرلەڭ.

خاتىرىنىڭ ئاساسلىق قۇرۇلمىسى:

```json
{
  "id": 19,
  "phase": 5,
  "title": "يېڭى دەرسنىڭ قىسقا ماۋزۇسى",
  "term": "English technical term",
  "objective": "ئۆگەنگۈچى دەرس ئاخىرىدا نېمە قىلالايدۇ؟",
  "summary": "دەرسنىڭ قىسقا چۈشەندۈرۈشى.",
  "detail": "ئاددىي ۋە ئېنىق دەرس تېكىستى.",
  "rule": "بۇ ئۇقۇمنىڭ ئاساسلىق قارار قائىدىسى.",
  "theme": {
    "name": "كۆك",
    "accent": "#7cbcff",
    "glow": "#255799",
    "soft": "#182e4b"
  },
  "demo": {
    "type": "workflow",
    "title": "تەلەپتىن نەتىجىگىچە",
    "mission": "ھېسابلاشقا قورال لازىممۇ دەپ پەرەز قىلىپ، قەدەممۇ قەدەم سىناڭ.",
    "prediction": {
      "kind": "workflow",
      "question": "قورال لازىممۇ؟",
      "choices": [
        {"value": "tool", "label": "قورال كېرەك"},
        {"value": "direct", "label": "بىۋاسىتە جاۋاب يېتەرلىك"}
      ]
    },
    "label": "مەشىق مىسالى",
    "disclaimer": "بۇ تەجرىبە پەقەت ساختا سانلىق مەلۇمات بىلەن ئىشلەيدۇ.",
    "fields": [{
      "id": "task",
      "label": "ساختا تەلەپ",
      "type": "select",
      "value": "calculate",
      "options": [
        {"value": "calculate", "label": "ھېسابلاش"},
        {"value": "chat", "label": "قىسقا سالام"}
      ]
    }],
    "steps": ["تەلەپ", "تەكشۈرۈش", "تاللاش", "نەتىجە"]
  },
  "quiz": {
    "question": "تەكشۈرۈش سوئالى؟",
    "choices": ["بىرىنچى جاۋاب", "ئىككىنچى جاۋاب", "ئۈچىنچى جاۋاب"],

```

`correct` نىڭ رەت نومۇرى نۆلدىن باشلىنىدۇ؛ `1` ئىككىنچى جاۋابنى كۆرسىتىدۇ. ھەر دەرسنىڭ `id` سىنى كېيىن ئۆزگەرتمەڭ، چۈنكى ساقلانغان تەرەققىيات شۇ بەلگە ئارقىلىق باغلىنىدۇ. `build` ۋە `activity` بولسا قوشۇمچە كود مەشىقى ئۈچۈن ئىشلىتىلىدىغان ئىختىيارىي مەيدانلار.

## تەجرىبە تىپلىرى

| `demo.type` | ئاساسلىق ئۇقۇم |
| --- | --- |
| `workflow` | نىشان، ھەرىكەت تاللاش ۋە قەدەملىك ئىجرا |
| `framework` | مودېل، SDK ۋە ئىجرا پروگراممىسىنىڭ مەسئۇلىيىتى |
| `patterns` | ۋەزىپىگە ماس لايىھەلەش ئەندىزىسى |
| `validation` | JSON، قورال نامى ۋە چەكلىك ھېسابلاشنى دەلىللەش |
| `rag` | مەنبە ئىزدەش ۋە دەلىل يېتەرلىكسىزلىكى |
| `approval` | ھوقۇق، ئىنسان تەستىقى ۋە رەت قىلىش |
| `planning` | بېقىنىش تەرتىپى ۋە قايتا پىلانلاش |
| `handoff` | پاكىت، مەنبە ۋە چىقىرىش شەرتىنى تاپشۇرۇش |
| `verification` | بەلگىلەرنى سېلىشتۇرۇش ۋە خاتا سېلىشتۇرغۇچنى سىناش |
| `observability` | قۇرۇلمىلىق ئىز ۋە مەخپىي مەزمۇننى چىقىرىپ تاشلاش |
| `protocol` | MCP بىلەن A2A نىڭ رولى |
| `context` | مەزمۇننى تاللاش ۋە مۇھىم شەرتنى ساقلاش |
| `memory` | خىزمەت ھالىتى، ئۇزۇن مۇددەتلىك ساقلاش ۋە ئۆچۈرۈش |
| `migration` | رامكىغا كۆچۈرگەندە قورال قائىدىسىنى ساقلاش |
| `computer` | چېكىشتىن كېيىن يېڭى ھالەتنى كۆزىتىش |
| `queue` | ۋاقىت چېكى، بىكار قىلىش ۋە تەكرار ئىجرادىن قوغداش |
| `locality` | مودېل، قورال ۋە خاتىرە مۇلازىمىتىنىڭ تور چېگراسى |
| `security` | پاكىت بىلەن ئىشەنچسىز كۆرسەتمىنى پەرقلەندۈرۈش |

مەۋجۇت تەجرىبە تىپىنى قايتا ئىشلىتىشتە، شۇ تىپنىڭ `fields` بەلگىلىرىنى ساقلاڭ. يېڭى ھەرىكەت لوگىكىسى كېرەك بولسا [js/ai-agent-demos.js](../../js/ai-agent-demos.js) دىكى تىزىملىككە بىر تىپ قوشۇڭ ۋە قۇرغۇچتىكى `known` تىپلىرىغا تىزىملاڭ؛ يول باشلاش، تەرەققىيات ۋە سوئال كۆرۈنمە يۈزىنى قايتا يېزىش ھاجەتسىز.

كۆرۈنمە يۈز لوگىكىسى: [js/ai-agent-learning.js](../../js/ai-agent-learning.js). كۆرۈنۈش ئۇسلۇبى: [css/ai-agent/learning.css](../../css/ai-agent/learning.css). ئۇيغۇرچە ئوقۇش خەت نۇسخىسى `assets/fonts/Bahij-Helvetica-Neue-Roman.ttf` دىن ئېلىنىپ، قۇرغۇچ ئارقىلىق HTML ئىچىگە قىستۇرۇلىدۇ؛ بىۋاسىتە ھۆججەتتىن ئېچىشتا خەت نۇسخىسىنى يۈكلەش چەكلىمىسى يوق، سىرتقى خەت مۇلازىمىتى ئىشلىتىلمەيدۇ.

## ھالەت ۋە ساقلاش چېگراسى

`Pending` — ئۇچۇر ياكى كېيىنكى قەدەم كۈتۈلمەكتە؛ `Failed` — بېكىتىلگەن تەكشۈرۈشتىن ئۆتمىدى؛ `Denied` — ئىجازەت رەت قىلىندى؛ `Cancelled` — ۋەزىپە بىكار قىلىندى؛ `Completed` — شۇ مەشىقنىڭ تەكشۈرۈش شەرتى ئورۇندالدى. ھەر بىر ھالەت رەڭ بىلەنلا ئەمەس، ئۇيغۇرچە ۋە ئىنگلىزچە ھالەت نامى بىلەنمۇ كۆرسىتىلىدۇ.

دەرس تەرەققىياتى `agent-lab-interactive-v1` ناملىق `localStorage` خاتىرىسىدە ساقلىنىدۇ. بۇ توركۆرگۈچ ياكى ھۆججەت ئورنى ئۆزگەرسە، ئىلگىرىكى خاتىرە كۆرۈنمەسلىكى مۇمكىن. يەرلىك ساقلاش چەكلەنسە، بەت بۇنى ئېنىق بىلدۈرىدۇ ۋە دەرسلىك يەنىلا ئىشلەيدۇ. تەجرىبە ئىچىدىكى ساندان ۋە ساقلاش كۆرۈنۈشلىرى ۋاقىتلىق JavaScript ھالىتى؛ ھەقىقىي ساندان ياكى ھۆججەت ئەمەس.

## تەكشۈرۈش

```sh
node scripts/test-ai-agent-demos.mjs
node scripts/verify-ai-agent-lesson.mjs
python3 scripts/check-ai-agent-fonts.py
```

بىرىنچى بۇيرۇق تورسىز تەجرىبە لوگىكىسىنى تەكشۈرىدۇ. ئىككىنچىسى تۈردە بار Puppeteer ئارقىلىق HTML نى بىۋاسىتە ھۆججەتتىن ئېچىپ، سوئال جاۋابى، قايتا باشلاش، تېلېفون كۆرۈنۈشى، ھەرىكەت تەڭشىكى ۋە ساقلاشنى سىنايدۇ. بۇ ياردەمچى سىناقلار ئۈچۈن Node.js ۋە تۈرنىڭ ئېچىش تايىنىشچانلىقى كېرەك؛ دەرسنى ئوقۇش ئۈچۈن ئۇلار تەلەپ قىلىنمايدۇ.

بۇ تەجرىبىلەر ئاگېنت ئۇقۇمىنى ئۆگىتىدۇ؛ ھەقىقىي مودېل سۈپىتى ياكى ئەمەلىي سىستېما بىخەتەرلىكىنى ئۆلچىمەيدۇ.

سىناق دوكلاتلىرى: [تەجرىبە لوگىكىسى](demo-validation.json) ۋە [تورسىز توركۆرگۈچ تەكشۈرۈشى](interactive-validation.json).

خەت نۇسخىسى ۋە ھەرىكەت يېڭىلىنىشى: ئوقۇش تېكىستىدە Bahij، چوڭ ماۋزۇلاردا Alkatip Rukki ئىشلىتىلىدۇ؛ ھەر ئىككىسى assets/fonts دىن ئېلىنىپ HTML غا قىستۇرۇلدى. تېما بەلگىلىرى، جەريان يولى، ساختا مائۇس ۋە ئەستە ساقلاش مىساللىرى ئۆگەنگۈچى ھەرىكەت قىلغاندا جانلىنىدۇ. [تولۇق كۆرۈنمە يۈز باھاسى ۋە تەۋسىيەلەر](full-review.md).

يېڭى ئۆگىنىش قائىدىسى: دەسلەپ پەرەز قىلىپ، ئاندىن ئىجرا قىلىپ سېلىشتۇرۇڭ؛ «ئەركىن سىناش» ھالىتىمۇ بار. دەرسنى تاماملاش ئۈچۈن مەشىقنى ئىجرا قىلىپ، سوئالغا توغرا جاۋاب بېرىش كېرەك. تەرەققىيات كۇنۇپكىسىدىن JSON چۈشۈرۈش، يۈكلەش ۋە تازىلاشقا بولىدۇ. [تولۇق يېڭىلىنىش ۋە سىناق دوكلاتى](recommendations-completion.md).

خەت قىستۇرۇش ھەممە HTML چىقىرىشىدا scripts/ai_agent_fonts.py ئارقىلىق باشقۇرۇلىدۇ. WOFF2 ھۆججەتلىرى ئەسلىدىكى خەت نۇسخىلىرىنىڭ بارلىق Unicode ھەرپ خەرىتىسىنى ساقلايدۇ؛ دەرسنى ئادەتتىكى قايتا قۇرۇشتا خەت ئايلاندۇرۇش قورالى لازىم ئەمەس.
